# 试剂库存台账

面向生物试剂库存监测的本地优先 Web 应用，适配 PC 与手机。每次导入新的入库表会建立一个新的库存快照周期；之后的出库记录只从当前周期扣减。

## 数据规则

- 入库表优先读取名称含“亿丰”的工作表，找不到时读取第 2 个工作表。
- 库存以“货号 + 批号”为批次粒度。
- 出库优先按批号精确匹配，其次尝试唯一货号或唯一产品名称。
- 重复的出库来源记录会自动跳过；无法匹配或超出库存的记录进入待处理状态。
- 数据保存在浏览器 `localStorage`，不会上传。请定期从“数据设置”下载 JSON 备份。

## 本地运行

```bash
npm install
npm run dev
```

## 发布

推送到 GitHub `main` 分支后，仓库中的 GitHub Actions 会构建并发布到 GitHub Pages。首次使用需在仓库 Settings → Pages 中选择 GitHub Actions 作为来源。
